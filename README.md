# Data Analysis & Machine Learning

This notebook contains practical data analysis and machine learning work using Amazon product/review data and the Titanic dataset.

The Amazon dataset was cleaned and explored to analyze product information, prices, discounts, ratings, categories, and review lengths. The data was then prepared for machine learning by converting values into usable numerical formats, scaling numerical features, and encoding categorical data.

The Titanic dataset was used to build a classification model that predicts passenger survival. Missing values were handled, categorical and numerical features were preprocessed, and a Logistic Regression model was trained and evaluated on the data.
